# CERTCHECK

**SSL Certificate Monitor & Alerting Tool**

## Features

- 🚀 Fast and efficient
- 📦 Single binary, no dependencies  
- 🔧 Easy to use
- 🔒 Secure by design

## Installation

```bash
git clone https://github.com/simplestar-992/certcheck.git
cd certcheck
go build -o certcheck .
```

## Usage

```bash
./certcheck --help
```
